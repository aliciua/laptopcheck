LaptopCheck

Ноутбукту сатып алардан мурун текшериңиз

Сатуучу айткан мүнөздөмөлөрдү ноутбуктун көрсөткүчтөрү менен салыштырыңыз. Экранды, баскычтопту жана үндү да текшериңиз.

↓Windows үчүн жүктөп алуу 64 биттик Windows (Intel же AMD) · 9,2 МБ · Python орнотуунун кереги жок

Кантип колдонуу керек

  1. Бул баракты ноутбуктан ачыңыз

    Сатып алгыңыз келген ноутбуктан ушул шилтемени ачыңыз.

  2. Сатуучудан уруксат сураңыз

    Уруксат бергенде LaptopCheck.exe файлын жүктөп алып ачыңыз.

  3. Тез текшерүүнү баштаңыз

    Браузердеги кадамдарды аткарыңыз. Аягында чыккан маалыматты жарыя менен салыштырыңыз.

Алгачкы сыноо версиясы

Файлга санариптик кол коюла элек. Windows файлды ачууда эскертүү көрсөтүшү же аны бөгөттөшү мүмкүн.
