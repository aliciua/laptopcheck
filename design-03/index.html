Что можно проверить

Быстро в браузере
Экран, клавиатуру и звук. Откройте эту страницу на ноутбуке, который хотите купить.
Подробно в Windows
Память, процессор, диск и батарею. С разрешения продавца запустите приложение и введите характеристики из объявления для сравнения.

Результаты проверки остаются на ноутбуке.

У тестовой версии приложения пока нет цифровой подписи. Windows может показать предупреждение.
