Как проверить ноутбук

Результаты проверки хранятся на ноутбуке.

  1. Откройте сайт на ноутбуке

    Используйте устройство, которое хотите купить.

  2. Запустите проверку в браузере

    Проверьте экран, клавиатуру и звук. Скачивать приложение для этого не нужно.

  3. Сверьте характеристики

    С разрешения продавца запустите приложение для Windows, чтобы проверить память, процессор, диск и батарею.

У тестовой версии приложения пока нет цифровой подписи. Windows может показать предупреждение.
